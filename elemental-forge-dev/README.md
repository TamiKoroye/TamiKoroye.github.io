# Elemental Forge: development test build

This is the separate test deployment of the development branch (`claude/elemental-forge-3d-combat-ekzoii`), published at https://tamikoroye.github.io/elemental-forge-dev/ so it can be played full-screen in Chrome.

The public game at `/elemental-forge/` is not changed by this folder.

The build stamp in the bottom-left corner of the menu names the commit and reports how many martial-arts clips actually decoded.
