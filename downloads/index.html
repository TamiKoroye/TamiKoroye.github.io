Elemental Forge

Android test build r15 (version 0.2-dev, 17 Nov 2026). Runs offline, fullscreen, landscape.

Download the app (10 MB)
  1. Open the downloaded file.
  2. If Android asks, allow "Install unknown apps" for Chrome or Files, then go back and tap Install.
  3. If Play Protect warns that it does not recognise the app, choose "Install anyway".
  4. Newer builds install over the old one; you do not need to uninstall.
